# Kalorifer Borusunun Gece Konseri Ruhsatı

> **Resmi uyarı:** Bu yazılım, kış gecesi 03:17'de duvarın içinden gelen *glonk-glonk-tiiinnn* sesinin bir arıza değil, sanat olduğunu iddia eder. İtirazlar Daire 4B'ye dilekçeyle yapılır. Dilekçe kâğıdı ısınmaz.

## Bu nedir?

Türkiye'nin ilk **kalorifer borusu konser ruhsat otoritesi**. Program şunları yapar:

1. Borusunun sahne adını belirler ("Paslı Tenor", "İkinci Kat Bası", "Vana Solo").
2. Desibel ölçer (bilimsel yöntem: rastgele sayı + kış katsayısı).
3. Komşu itirazlarını diplomatik notaya çevirir.
4. Gece 03:00–05:00 arası için **geçici sanat ruhsatı** basar.
5. Encore isterse ısıyı 1 derece artırır. Kimse fark etmez.

Çalışır. Gerçekten. Hayatınızı düzeltmez.

## Kurulum

```bash
python3 ruhsat.py
```

Bağımlılık yok. Sadece Python 3 ve biraz sabır. Kalorifer açıksa daha iyi çalışır (bilimsel kanıt yok, his var).

## Örnek çıktı

Program size resmi bir ruhsat, ölçüm tutanağı ve varsa komşu notası basar. Kağıda yazdırıp vanaya bantlamanız tavsiye edilir.

## Sık sorulan sorular

**Bu yasal mı?**  
Yasal olan şey ile ısınan şey aynı değildir.

**Neden 03:17?**  
Çünkü 03:16 henüz ısınmamıştır, 03:18'de herkes uyanmıştır. Altın saat.

**Copilot buna ne der?**  
Muhtemelen "bu bir HVAC protokolü mü?" der. Hayır. Bu sanat.
